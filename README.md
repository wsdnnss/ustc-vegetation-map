# 中科大本部植被分布 · 校园植物地图

> 课程作业演示项目 · 不公开、不商用

一个基于 **Vue 3 + Vite + Leaflet** 的校园植被分布可视化网页，包含「分布地图 / 物种库 / 季节专题 / 物种详情 / 上传投稿」功能。物种数据以本地 JSON 维护；用户投稿与社区帖子由项目自带的 Node 数据服务写入科大云盘同步文件（未启动服务时回退浏览器本地存储），**无需外部数据库**。

---

## 一、功能概览

| 页面 | 路径 | 功能 |
|---|---|---|
| 分布地图 | `/#/` | 仅覆盖科大**中校区**；按「科 / 花期 / 关键词」筛选，相近点位自动**聚合**，搜索框支持**联想**并定位到物种 |
| 物种库 | `/#/species` | 229 种（已记录 20 · 待核实 209），支持**搜索联想**（中文名/学名/别名/科）与「科 / 花期 / 类别 / 状态」筛选 |
| 季节专题 | `/#/season` | 12 个月份切换，按「观花 / 观果」查看当月物候清单，可一键跳回地图查看当月分布 |
| 物种详情 | `/#/species/:id` | 物种信息 + **识别特征 / 学名来源** + 分布点列表 + 迷你地图 + 我的投稿照片 |
| 上传投稿 | `/#/upload` | 上传照片、地图选点、保存、导出/导入数据 |
| 批量导入 | `/#/batch` | 粘贴/上传表格（CSV / Excel）+ 批量选照片，一次导入多条 |
| 使用说明 | `/#/about` | 项目说明与免责声明 |

## 二、技术栈

- 前端：Vue 3（组合式 API）
- 构建：Vite 5
- 地图：Leaflet 1.9 + leaflet.markercluster 1.5（点位聚合）；默认高德瓦片，可选接入**天地图**（官方 WMTS，需申请 Key）
- 路由：Vue Router 4（hash 模式）
- 数据：`src/data/species.json` + 科大云盘同步文件 `植物地图数据.json`（照片单独存放在同目录 `图片/`，未启动本地服务时回退浏览器 `localStorage`）
- 本地服务：Node `server.mjs`（静态托管 + 按条写入的数据接口）；共享时可启用访问口令
- 测试：Vitest（坐标转换、表格解析、物种筛选与数据分级）

## 四、快速开始

### 1. 环境要求
- Node.js ≥ 18（当前机器已装 v24）
- 包管理器：pnpm（或 npm）

### 2. 安装依赖
```powershell
pnpm install
```

### 3. 启动开发服务器
```powershell
pnpm dev
```
浏览器打开终端显示的地址（默认 <http://localhost:5173/>）。

### 4. 构建 / 预览（用于提交或部署）
```powershell
pnpm run build     # 产物在 dist/
pnpm run preview   # 本地预览构建结果
```

### 5. 数据校验与测试
```powershell
pnpm run validate:data   # 检查 id 重复、越界坐标、已记录无点位、50 m 内重复点等
pnpm test                # 坐标转换 / 表格解析 / 物种筛选 / 数据分级
```

### 6. 一键共享（含访问口令）
双击 `start-share.bat`：自动构建、选端口、打印 IPv6 地址，并生成一个**随机访问口令**。队友首次打开会看到浏览器登录弹窗，用户名任意，密码填窗口里打印的口令。

> 如需固定口令，先执行 `set VEG_ACCESS_TOKEN=你的口令` 再双击脚本；直接用 `node server.mjs` 启动且不设该变量时不启用口令。

## 五、图片上传怎么用

进入「上传投稿」页面，按以下步骤：

1. **① 选择照片**：点击虚线框 → 选一张本地图片（JPG/PNG）。系统会自动**等比压缩到宽 ≤ 900px 的 JPEG**，避免占满存储。
2. **② 物种信息**：从下拉框选择物种（会自动填名称），找不到就手动填写；不确定可填「待鉴定」。
3. **③ 采集位置**：在**小地图上点一下**即可选点；也可直接填经纬度，或点「用校园中心」。
4. **备注**：可选，例如「东区樱花大道旁，盛花期」。
5. **保存投稿** → 提示成功后，回到「分布地图」即可看到橙色标记（记得勾选「显示我的投稿」）。

**注意事项**
- 投稿与社区帖子保存在**科大云盘同步目录** `E:\科大云盘\云盘文件\科大植物地图\植物地图数据.json`，用 `pnpm dev` 或 `start-share.bat` 启动时自动读写，换浏览器或清缓存不会**丢失**。
- 写入方式是**按条追加/删除**（`POST /api/submissions`、`DELETE /api/submissions/:id` 等），不再整表覆盖，多人同时发帖不会互相冲掉。
- 照片保存为同目录 `图片/` 下的独立文件，JSON 只记录图片地址；删除帖子/投稿时服务端会一并删除对应照片。
- 若直接打开 `dist/index.html`（未启动本地服务），会自动回退到 `localStorage`（照片以 base64 内嵌），此时仍需定期导出备份。
- 备份整个云盘目录（`植物地图数据.json` + `图片/` 文件夹）即可完整迁移；也可以双击 `backup-data.bat` 自动打包到 `backups/`。
- 演示前可用 `reset-demo.bat` 清空帖子、投稿和照片（会先自动备份），快速回到空白演示状态。
- 建议定期点「**导出 JSON**」备份，换环境后用「**导入 JSON**」恢复（重复 id 会被跳过）。

## 六、批量导入（多人调查 → 一人录入）

适合「**4 人现场调查 → 发到群里 → 1 人统一录入**」的流程。进入「批量导入」页，三步完成：

**① 准备表格**：列顺序为 `物种, 纬度, 经度, 备注, 照片文件名, 采集人`（有表头会自动识别）。
- 可直接从 **Excel/WPS 框选复制后粘贴**到输入框；
- 或点「上传 CSV / Excel」：支持 `.csv`、`.tsv`、`.xlsx`、`.xls`（CSV 自动兼容 UTF-8 / GBK 编码，Excel 读取第一个工作表）；
- 或点「**下载 CSV 模板**」按模板填写。

**② 选择照片**：一次多选，系统按表格里的「照片文件名」自动匹配（写全名 `IMG_0001.jpg` 或前缀 `IMG_0001` 都行），并自动压缩。

**③ 预览并导入**：表格会标出每行状态——
- `可导入`：物种与经纬度有效；
- `有误`：缺物种名 / 纬度或经度无效（该行会被跳过）；
- `未匹配`：填了照片名但没找到对应照片（仍可导入，只是无图）。

确认后点「导入 N 条记录」，数据即进入本机（与手动上传的投稿合并）。

> 提示：照片会保存为云盘 `图片/` 目录下的独立文件，导入时逐张写入；批量较大时请等待提示完成再关闭页面。

**多人分别导出后合并**：各自在「上传投稿」导出 JSON 后，在项目目录执行：

```powershell
pnpm run merge:exports submissions-export-2026-10-20.json submissions-export-2026-10-21.json
```

脚本会按 `id` 或「物种 + 坐标 + 备注」去重（重复项优先保留带照片的），输出 `submissions-merged-YYYYMMDD.json`，可再导入。

## 七、数据服务与接口

数据服务在 [server/store.js](file:///E:/ustc-vegetation-map/server/store.js)，数据文件结构保持不变（`ustc-veg-community-posts` / `ustc-veg-submissions` / `ustc-veg-community-author`）。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/store` | 读取全部数据（页面初始化用） |
| POST | `/api/posts` | 新增帖子 |
| POST | `/api/posts/batch` | 批量迁移/导入帖子 |
| DELETE | `/api/posts/:id` | 删除帖子（同时删除关联照片） |
| POST | `/api/submissions` | 新增投稿 |
| POST | `/api/submissions/batch` | 批量导入投稿（重复 id 跳过） |
| DELETE | `/api/submissions/:id` | 删除单条投稿（同时删除照片） |
| DELETE | `/api/submissions` | 清空全部投稿 |
| PUT | `/api/author` | 保存昵称 |
| POST | `/api/images` | 保存照片（接收 data URL） |
| GET / DELETE | `/api/images/:name` | 读取 / 删除照片 |

- 写入在进程内串行化，每次都先读最新文件再追加，**不再整表覆盖**。
- JSON 解析失败时**拒绝写入**，避免把损坏文件覆盖为空数据。
- `VEG_ACCESS_TOKEN` 开启整站 HTTP Basic：用户名任意，密码为口令；`start-share.bat` 会自动生成随机口令。
- HTTP Basic 只能挡住误操作和随手扫描，不能替代 HTTPS；课堂演示用途足够，正式系统请上 HTTPS 与独立账号体系。

## 八、数据维护

### 修改物种数据
编辑 [src/data/species.json](file:///E:/ustc-vegetation-map/src/data/species.json)，字段说明：

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识（如 `sp001`） |
| `nameCn` | 中文名 |
| `nameLatin` | 学名（斜体显示） |
| `family` / `genus` | 科 / 属 |
| `habit` | 生活型（如「常绿乔木」） |
| `tags` | 标签数组 |
| `alias` | **别名数组**（可选，用于检索与展示） |
| `identify` | **识别特征**（可选，图鉴式要点） |
| `nameOrigin` | **学名来源 / 命名释义**（可选） |
| `bloomMonths` | **花期月份数组**（1–12，用于筛选） |
| `bloomText` / `fruitText` | 花期 / 果期文字 |
| `imagePrompt` | 无 `imageUrl` 时的文生图提示词 |
| `imageUrl` | 可选，**优先使用**；填本地路径或网络地址 |
| `description` | 简介 |
| `points` | 分布点数组，见下方说明 |
| `status` | `已记录`（有点位）/ `待核实`（候选清单） |

`points` 单项结构：

```jsonc
{
  "lat": 31.8418,
  "lng": 117.2624,
  "location": "中区北门主干道",
  "source": "实地调查",        // 可选：实地调查 / 示例坐标 / 公开资料整理
  "coordAccuracy": "±3 m"      // 可选：精度说明；缺省按示例坐标展示
}
```

> 不写 `source` 时，页面统一按「示例坐标（约 ±50 m，未实测）」展示；补上 `source: "实地调查"` 后，详情页徽章会变为「实地调查」。

### 把图片换成真实照片（两种方式）
1. **放进项目**：把照片放到 `public/images/` 目录，在 `species.json` 里给该物种加 `"imageUrl": "/images/你的文件名.jpg"`。
2. **用采集功能**：通过「上传投稿」拍照上传，照片会显示在对应物种详情页的「我的投稿照片」里。

### 物种的两个状态（重要）
物种库里每种植物都有 `status` 字段：

| status | 含义 | 是否显示在地图上 |
|---|---|---|
| `已记录` | 有校园分布点位（`points` 非空） | ✅ 会显示标记 |
| `待核实` | 按**合肥（华东）地区常见种**列入的候选，尚未在校园内定位 | ❌ 暂不显示 |

- 目前：**已记录 20 种**（共 42 个分布点）、**待核实 209 种**。
- 「待核实」物种详情页会显示"尚未在校园内定位"的提示，等你实地确认后补点位即可。

> 📖 **参考书目**：物种库规模（229 种）与「识别特征 / 学名来源」字段体例参考
> **《中国科学技术大学校园植物图鉴》**（钱栎屾、邱燕宁 著，沈显生 指导，中国科学技术大学出版社）。
> 本项目**未使用该书原文**，除已记录 20 种外的物种为公开资料整理的候选清单，不代表该书内容。
> 上述信息同步保存在 `src/data/species.json` 的 `meta.reference` 中，并展示于「使用说明」页。

**把某个「待核实」物种转为「已记录」**：编辑 `src/data/species.json` 中该物种
1. 把 `status` 改成 `"已记录"`；
2. 在 `points` 里填入分布点，例如 `[{ "lat": 31.8395, "lng": 117.262, "location": "中区中心广场" }]`。

> ⚠️ 说明：物种库中「待核实」部分是基于地区常见植物整理的**候选清单**，不是实地调查结果；要精确到"校园里真实存在哪些植物"，需要实地踏查确认。

### 关于坐标
- 当前 `points` 为**近似示例值**，仅用于演示。
- 数据统一以 **GCJ-02**（高德/腾讯）保存；天地图、GPS 使用 **WGS-84 / CGCS2000**，两者在合肥相差约 **565 m**。
- 切换到天地图底图时，应用会**自动把点位换算为 WGS-84**；切回高德时再换回，`species.json` 无需改坐标。

### 底图与缩放策略

底图只保留 **3 种**，默认「天地图影像（含影像注记）」；未配置天地图 Key 时回退到「高德标准地图」。

| 底图 | 坐标系 | 说明 |
|---|---|---|
| **天地图影像（含影像注记）** | CGCS2000 | 默认（配置 Key 时）；官方影像 `img` + 注记 `cia` |
| 天地图矢量（含矢量注记） | CGCS2000 | 官方矢量 `vec` + 注记 `cva` |
| 高德标准地图 | GCJ-02 | 矢量路网 + 建筑轮廓 + 注记；无 Key 时默认 |

#### 天地图接入（需 Key）

天地图是国家地理信息公共服务平台，底图权威、图层规范，但**必须申请 Key**。

**① 申请 Key（免费）**
1. 打开天地图控制台 <https://console.tianditu.gov.cn/>（或从 <http://lbs.tianditu.gov.cn/> 点「控制台」）。
2. 注册并登录 → 申请成为**个人开发者**（需实名认证）。
3. 「应用管理」→「创建应用」：应用类型选**浏览器端**；域名白名单**本地开发建议留空**（表示不限制域名），或只填 `127.0.0.1`。注意：天地图控制台不接受 `localhost`，填了会报「域名有误」；部署后再填实际域名。
4. 创建完成后，在应用详情中复制 **tk**（一串字符，即 Key）。
5. 若用 `localhost` 访问时天地图瓦片返回 403（`code: 301007`，域名不匹配），说明白名单里没有 `localhost`；清空白名单即可，或改用 `127.0.0.1` 访问。

**② 在项目中配置**
在项目根目录新建 `.env.local`（已在 `.gitignore` 中忽略），写入：

```ini
VITE_TIANDITU_TK=你的tk
```

重启 `pnpm dev`（或重新 `pnpm run build`）。图层控件会出现「天地图影像（含影像注记）」「天地图矢量（含矢量注记）」，并默认选中影像。

> 注意：天地图影像原生最高 **18 级**；实测 19/20 级返回的是空白占位图，因此地图 `maxZoom` 已设为 **18**，不再做无意义的拉伸放大。

**清晰度策略**
- 所有底图限制在原生 **18 级**，避免 19/20 级插值放大导致的影像和文字发虚；
- 18 级起在每个分布点旁显示物种名称标签；
- 瓦片关闭浏览器平滑插值（`image-rendering: -webkit-optimize-contrast`），文字注记更锐利。

> ⚠️ **坐标系很关键**：天地图为 **WGS-84（CGCS2000）**，高德为 **GCJ-02**，两者在合肥相差约 **565 m**。应用会自动换算显示坐标；手动编辑 `points` 时仍应以 **GCJ-02** 保存。

## 九、页面操作细节

### 3 分钟演示路径

1. **分布地图**：按「科 = 樟科」筛选 → 点击任意绿色标记 → 弹窗里看到「坐标：示例坐标」→「查看详情」。
2. **搜索联想**：在搜索框输入「樟」，下拉会列出中文名/别名/学名命中的物种，回车或点击即定位到该物种（地图页）或进入详情（物种库）。
3. **点位聚合**：缩小到 17 级时相近点位会合并为数字圆圈，点击数字放大到 18 级即可展开并看到物种名称。
4. **物种详情**：展示识别特征、学名来源、分布点列表与迷你地图，注意「示例坐标」徽章。
5. **季节专题**：进入「季节专题」→ 切换月份 → 在「观花 / 观果」间切换 → 点「在地图上查看本月开花」回到地图（自动带上花期筛选）。
6. **上传投稿**：选一张照片 → 用校园中心 → 保存 → 回到地图勾选「显示我的投稿」，出现橙色标记。
7. **批量导入**：上传一个 `.xlsx` 或粘贴几行表格 → 预览 → 导入。
8. **社区**：发一条带图的帖子 → 说明数据已落入科大云盘。

演示前建议先执行 `backup-data.bat`；演示后可执行 `reset-demo.bat` 恢复空白状态。

### 交互细节
- **地图筛选**：顶部工具栏可组合「科 + 花期 + 关键词」，下方实时显示「分布点 / 物种」数量；点「重置」清空条件。
- **搜索联想**：输入即匹配中文名、别名、学名、科、属与标签，支持 ↑↓ 切换、回车选择、Esc 关闭；输入框为空时展示「本月开花」的观察建议。
- **标记聚合**：17 级自动聚合相近点位，数字为聚合数量；点击聚合标记会放大并在 18 级完全展开。
- **季节专题**：月份条上的数字随「观花 / 观果」模式切换；花期为 0 的物种（竹类罕见开花、蕨类孢子繁殖）不参与月度统计。
- **底图切换**：地图右上角图层控件可在「天地图影像」「天地图矢量」「高德标准地图」3 种底图间切换，默认天地图影像；未配置 Key 时只显示高德标准地图。
- **缩放增强**：地图限制在原生 18 级，避免拉伸发虚；18 级时显示物种名称标签。
- **详情页**：左侧为分布点清单，右侧迷你地图会自动缩放到全部点位。

## 十一、常见问题

| 问题 | 处理 |
|---|---|
| 端口被占用 | `pnpm dev --port 5174` |
| 浏览器弹出登录框 | `start-share.bat` 启用了访问口令：用户名任意，密码填窗口里打印的口令 |
| 数据文件损坏 / 写入报错 | 服务会拒绝写入以保护原文件；先复制一份 `植物地图数据.json`，再用编辑器修复 JSON |
| Excel 导入提示读取失败 | 只读取第一个工作表；确认表头/列可识别，或改存为 CSV 再导入 |
| 物种图片不显示 | 无网络时文生图不可用，会自动显示「暂无图片」占位；可改用 `imageUrl` 本地图片 |
| 投稿不见了 | 先检查云盘数据文件 `植物地图数据.json`；若被误删，浏览器 localStorage 缓存会在下次启动时自动迁回云盘 |
| 页面提示「未连接本地数据服务」 | 用 `pnpm dev` 或 `start-share.bat` 启动，不要直接双击 `dist/index.html` |
| 地图空白/瓦片加载慢 | 页面底部会出现「底图瓦片加载失败」提示；切换底图或检查网络 |
| 命令行提示 `pnpm` 不是命令 | 重启终端/IDE 让 PATH 生效 |
